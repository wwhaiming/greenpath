GreenPath system map

Turns the U.S. green-card maze into one obvious next step — plain-language, grounded in real wait-time data, in any language. General information, never legal advice.

Whaiming Wang · Gary Zhang // React + Vite · Flask · OpenAI gpt-4o-mini
1 Architecture — one input → AI (grounded) → one structured answer
Input

The user, in their own words

"My wife is a citizen, I came on a tourist visa." Any language. Often on a phone, filing without a lawyer.

Frontend

React SPA

11 pages, no router dep. Sends free text to the Flask API. OCR / PDF / read-aloud run in-browser.

Backend + AI

Flask /api/* → gpt-4o-mini

5 endpoints. System prompt + real-data brief → model → strict JSON, validated server-side.

Output

Plain-language result

Pathway · issues · next question · answer — with a confidence level and a pointer to the official source.

Grounding

Not just a wrapper. visa_data.py + forecast.py read the vendored Visa Bulletin dataset and fitted priority-date advancement rates, then inject a factual brief into the Pathway & Q&A prompts. So "how long will I wait?" is answered with real historical movement for the user's country + category — flagged as changing monthly, verify at travel.state.gov.

2 Seven features · five AI endpoints
Pathway Finder grounded

Situation → likely category + confidence + next steps.

Stage Q&A grounded

Plain answers tuned to pathway + stage, in any language.

Document Review AI · JSON

Form entries → severity-ranked RFE-risk issues.

Interview Prep AI · JSON

USCIS-style officer, one question + coaching at a time.

Deadline Alerts AI + offline

One sentence → dated timeline. Rule-based fallback.

Language Tools in-browser

Translate · detect · OCR · PDF · read-aloud, 100+ langs.

Guided Walkthrough no AI

Stage-by-stage roadmap, saved in localStorage.

Progress Tracking no AI

Interactive checkpoints; "see what comes next."

Responsible AI guardrail

Risk: a scared user treats AI output as a legal decision in an irreversible process.

Guardrail: prompts refuse legal advice; uncertain inputs must return "Unclear — needs attorney review" + a confidence level instead of guessing. Facts grounded in real data. No accounts, nothing stored server-side.
