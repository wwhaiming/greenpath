# PERM labor-certification outcomes (successful vs unsuccessful)

Permanent labor certification (PERM) is the U.S. Department of Labor step of an
employment-based green card. Each case ends Certified / Certified-Expired (success)
or Denied / Withdrawn (unsuccessful) -- the clearest public "successful vs
unsuccessful green card" signal.

**FY2024: 92,258 cases -> 86,319 certified (93.6%), 4,892 denied (5.3%).**

- `perm_fy2024_by_status.csv` -- counts + pct by case status
- `perm_fy2024_by_country.csv` -- certified / denied / withdrawn + denial rate by country of citizenship

Derived from the DOL OFLC disclosure file (raw ~76MB, case-level): https://www.dol.gov/sites/dolgov/files/ETA/oflc/pdfs/PERM_Disclosure_Data_FY2024_Q4.xlsx
Source: U.S. DOL OFLC (public domain). Educational only, not legal advice.
